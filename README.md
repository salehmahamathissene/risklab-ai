# RiskLab AI 🚀

RiskLab AI is a unified risk intelligence platform combining:

- ✈️ Airline disruption compensation forecasting (EU261 Monte Carlo)
- 🛡️ SOC security analytics & threat detection dashboards
- 🌊 Scientific simulation engines (Navier–Stokes CFD lab)

## Modules

### 1. Airline Risk Engine
Forecast expected compensation exposure, P50/P95 worst-case cost, and top disruption drivers.

### 2. SOC Threat Detection
Upload logs, detect brute-force attacks, and generate SOC-ready PDF reports.

### 3. Simulation Lab
High-performance fluid dynamics solvers and benchmark simulations.

## Tech Stack
- FastAPI
- Pandas
- Monte Carlo Simulation
- Cybersecurity Analytics
- Scientific Computing (CFD)

## Vision
Build the first African-born open risk simulation platform for aviation, security, and engineering.
